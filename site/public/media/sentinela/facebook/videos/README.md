# Facebook — vídeos locais

Pasta opcional para arquivos **MP4** de Reels ou vídeos da página **Better Controle de Pragas** (Sentinela Saúde Ambiental), quando houver arquivo baixável e uso autorizado.

**Observação:** muitos Reels só reproduzem no Facebook/App com login; nem sempre há link MP4 público estável. Não commits de material sem direito de uso.

Para incluir vídeo na home, prefira arquivo em `public/…` definido pela equipe ou `NEXT_PUBLIC_*` conforme `src/lib/brand.ts`.
