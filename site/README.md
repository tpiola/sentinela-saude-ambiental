# Aplicação web (`site`)

Projeto [Next.js](https://nextjs.org) criado com [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app), em português do Brasil na interface.

## Como rodar

Na pasta `site/`:

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000). Ao editar `src/app/page.tsx`, a página atualiza automaticamente.

Este projeto usa [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) com a família [Geist](https://vercel.com/font).
