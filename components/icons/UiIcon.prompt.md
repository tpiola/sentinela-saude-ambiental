Ícones funcionais de interface (telefone, menu, fechar, chevron, seta, pin, documento, agenda, escudo) no traço outline 2px do site.

```jsx
<UiIcon name="chevron-down" size={12} strokeWidth={3} />
```

Nunca use emoji como ícone funcional: o site reserva emoji para o menu de pragas legado. Para o WhatsApp use `WhatsAppIcon`.
